## What v2 changes

- **New `interests` output** — personal interests and passions as a flat lowercase text array (same format as `deep-person-basic` #12833 v4.17), e.g. `["photography", "music"]`. Sanitized (trim, lowercase, dedupe, drop empties, max 8) and **merged** into `master_person.interests`: existing values from other writers are kept verbatim, only new unique values are appended, and empty-string entries are dropped in passing. The field is shared with the deep-bio landing path, so v2 never overwrites it.
- **Model: `x-ai/grok-4.6`** (was grok-4.5). Same $$2/$$6-per-M pricing and ZDR-clean, but it burns ~2.2x the reasoning tokens for visibly better output: direct quotes, dated anchors, and coverage-gap insights. A `model` input overrides per call for future A/Bs.
- **Richer insight dimensions** — the v2 prompt explicitly prioritizes: topics and themes the person posts/speaks about, stated opinions and affinities (what they praise vs push back on, evidence-anchored), and communication style (tone, format preference, credit-vs-self-promote), ahead of the v1 dimensions.
- **Third bounded Exa query** for personal-interest evidence (4 results, 700 chars), alongside the two v1 searches; the recent-activity query dropped its investor-specific bias terms.
- **System/user message split** — instructions travel as the system message, evidence as the user message; evidence bounding (45k/18k) applies to the user message only.
- **deep\_bio capped** at 8,000 characters of whole paragraphs before prompt assembly.
- **v2-tagged telemetry** — history rows use source `OpenRouter Social Insights v2`; audit rows log `interests_from_llm`, `interests_merge`, and the raw `interest_evidence` snippets so every persisted interest is traceable to its source.

### Prompt-tuning note: grok-4.6 is stricter

Under the shared evidence hierarchy ("deep\_bio is not independent proof"), grok-4.6 returned **zero** interests where grok-4.5 returned four — its deeper reasoning applied the discipline rules literally. Prompt v2.2 therefore carves out interests: for that output only, an explicit bio/deep\_bio statement ("an accomplished photographer and musician") is a sufficient source, with expand-generic-to-specific and no-invention rules. Insights keep the strict hierarchy.

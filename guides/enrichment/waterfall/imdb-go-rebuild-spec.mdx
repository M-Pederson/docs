## 1. Executive Summary

The IMDB (Film & TV) waterfall enriches people and titles from public IMDb pages: **Firecrawl scrape → LLM extraction → relational rows → FalkorDB graph writes → bounded, tiered cascade**. There is no IMDb API — every entity is a markdown scrape of `imdb.com/name/nm…` or `imdb.com/title/tt…` plus an optional `/awards/` scrape, LLM-extracted to structured JSON.

The rebuild target is a Go service on Cloud Run writing to AlloyDB (`universe.*` schema) and the greenfield Universe FalkorDB graph, per the [GCP migration plan](/guides/open-work/orbiter-univers-standalone/enrichment-gcp-migration). Parity-first (migration decision #3): reproduce the orchestration order, dedup, queue semantics, and graph shape below unless Mark signs off a deviation.

Shape of the pipeline, in one pass:

- **Two entry gates** — `get-add/imdb-person` #12873 and `get-add/imdb-title` #12874 — normalize the `imdb_url` natural key, dedup (person: 30-day freshness; title: permanent with sparse-stub fall-through and `refresh` bypass), then either sync-enrich (`cascade_depth == 0 && queue == false`) or upsert a queue row.
- **Two orchestrators** — `run-base-imdb-person-enrich` #12880 and `run-base-imdb-title-enrich` #12881 — run 7-phase flows (kill switch → scrape+extract → master rows → node/avatar/bio → credit edges → awards → cascades → success stamp) with per-phase `try_catch` → `log_crash`.
- **Three queues** — `queue_imdb_person` #706 and `queue_imdb_title` #707 (drained by INACTIVE 600 s single-row crons, Tasks 159/160), and `queue_imdb_award_graph` #764 (drained by the **ACTIVE** Task 191: 60 s tick, ≤20 jobs, worker `process-imdb-award-graph` #13245). Queue upserts are the sole writers and carry the 2026-07-25 semantics: one-step tier promotion toward 0 debounced to once per 30 minutes, explicit-lower-tier-wins clamped 0–4, and symmetric title↔award tier equalization.
- **Depth model** — hard cap at 2. Depth 0 seeds fan out fully; depth 1 queues only T1–T2 children at depth 2; depth 2 enriches without cascading; depth 3 is never queued.
- **Graph writes** — `Film_TV` (#2320), `Film_TV_Award` + award edges (#2334, three-tier MERGE-key priority), shared `Person` create/update (#2601/#2758), `WORKED_ON` credit edges (#13013/#13015, weight 30), `HAS_EXPERTISE` (#12926 family), all through the `send-cypher` #2815 transport whose **errors return as strings, never throws**.
- **Cross-waterfall bridges** — existing `master_person` rows attach via `add-imdb-to-master-person` #10509 (reverse-verified by Exa+LLM `verify-imdb-url` #12677); `kickoff-cross-waterfalls-from-expertise` #13185 routes expertise flags between pipelines.

This spec freezes a **2026-07-31 live snapshot** of 72 functions (Section 4). Unlike Company, **no hard freeze has been signed off for this pipeline** — re-verify `updated_at` against the manifest before building against any contract here.

Pipeline-specific notes:

- **Embeddings are a sanctioned parity break.** Live Xano writes dual vectors (OpenAI `text-embedding-3-small` 1536 `name_embedding` via #4676 + Gemini 3072 `embeddings` via #13114/#13125). Universe nodes carry **Gemini 1536 L2-normalized only** (decision #1). Reproduce *which fields get embedded*, not the dual-write.
- The Firecrawl client must reproduce #4515's coercion split: `first_notempty` inputs (timeouts, proxy — explicit `0`/`""` falls back to defaults 60000 ms / 60 s / `auto`) vs `first_notnull` inputs (content/cache flags — explicit `false`/`0` preserved), plus `soft_fail` semantics for optional awards scrapes.
- The graph package must expose the **string-error contract decision** (Section 20): in Xano, `send-cypher` #2815 returns Cypher errors as strings and most callers never check. In Go, graph writes return real errors; each call site's sheet says whether failure aborts or logs-and-continues.

## 7. End-to-End Worked Example

### Example A — seed person, happy path (Doug Liman-class: prolific director with awards)

Input (product or operator calls #12873):

```json
{ "imdb_url": "https://www.imdb.com/name/nm0510731/", "cascade_depth": 0, "queue": false }
```

Expected control flow:

1. Gate canonicalizes to the normalized URL key (`trim | split:"/?" | first | rtrim:"/"`, nm-id canonicalization) and misses dedup (no fresh `imdb_person` row).
2. Kill switch #12870 evaluates OFF → stub row ensured, `seed_imdb_person_id` defaults to the stub's own id.
3. `queue == false && cascade_depth == 0` → orchestrator #12880 runs synchronously (P1–P7).
4. P2 Firecrawl scrapes the name page (60 s timeout, hard-fail), LLM-extracts (`~google/gemini-flash-latest`), saves `json/markdown/name/image_url` on `imdb_person`.
5. P3 mints `master_person` + `master_link` + `birthday_join` (dedup-guarded); dates helpers upsert master-date rows.
6. P4a avatar/bio/node: #237 → #2536 → #2601/#2758; `node_uuid` + `master_person_id` stamped back; visibility set true.
7. P4b optional: LLM bios #2537, deep research #12833/#12747, social insights #12669, expertise #12666 → #13185 (`run_imdb:false, run_music:true`). Failures continue.
8. P4c credit edges #13013: `WORKED_ON` per credit whose film node exists; `imdb_credit_join` rows (pending `edge_created:false` for stubs).
9. P5 awards #12887: `/awards/` scrape (soft-fail), LLM extract, `film_tv_award` rows via #13246; ≤10 upgraded awards materialize inline via #13014→#2334; every remainder queued to #764 via #13244.
10. P6 cascades: #12875 (`sync_top_credits: 5` — top 5 titles enriched inline at the discovered depth), #13013 replay, #12877 (`shared_with` co-nominee people → person queue).
11. P7 stamps `enriched_at`, `enrich_success: true`, `cascade_depth: 0`.

Expected key AlloyDB writes (Universe mapping, Section 12):

| Table | Key | Important fields |
| --- | --- | --- |
| `universe.entity` ×N | strong identifier `imdb:nm0510731` (+ one per discovered title/person stub) | `entity_type`, `graph_node_uuid`, `enrichment_state` |
| `universe.imdb_person` | `imdb_id = nm0510731` (UNIQUE) | `scrape_fresh_at`, `credit_replay_state`, raw payload in `enrichment_payload` |
| `universe.film_tv` ×≈5 sync + stubs | entity FK; identifier `imdb:tt…` | title/year; poster only for sync-enriched |
| award rows | `(canonical_identity_key, person)` composite | winner/nominee, year, category |
| queue rows | one per queued child URL, unique | tier, depth 1–2, `count`, `last_promoted_at` |

Expected graph writes:

| Node/Edge | Key | Required properties |
| --- | --- | --- |
| `Person` | `uuid` (create #2601 / update #2758) | name, avatar, visibility true, embedding |
| `Film_TV` ×sync titles | `imdb_url` MERGE | label from 9-type whitelist, `node_uuid` stamped back |
| `WORKED_ON` ×credits | endpoints + role | weight 30, uuid coalesce, description at write |
| `Film_TV_Award` + `WON_AWARD`/`NOMINATED_FOR` | 3-tier MERGE key (#2334) | one award node per instance; one person edge per award row |

Acceptance checks:

- Re-running the same input inside 30 days returns `existing` — zero scrapes, zero new rows.
- Re-running after expiry preserves graph `created_at` on all MERGE-keyed nodes/edges; counts do not grow.
- The seed returns with ≤5 sync-enriched films; everything else is queue rows, not scrapes.

### Example B — dedup-hit + explicit-zero (the parity killers)

1. **Duplicate discovery:** while Example A runs, the same co-star `nm0000158` is discovered by two different titles. Expected: ONE `queue_imdb_person` row, `count = 2`, and tier promotion applied **at most once per 30-minute window** regardless of how many mechanical re-adds occur in the run. An explicitly lower incoming tier still wins immediately.
2. **Explicit zero:** a bootstrap/award-graph row written with `priority_tier: 0` must stay 0 — every tier default in the queue writers uses `first_notnull`-style semantics in Go (`*int`, nil = default 4, explicit 0 = 0). A Go port that maps "unset" to 0 or coerces 0 → 4 breaks the drain lane and the floor logic (#13244's unlinked floor).
3. **Award race:** two concurrent runs upsert the same `(film_tv_award_id, idempotency_key)` job — the second insert must land as a benign no-op (`count`/touch), not a crash row (live composite unique index).

### `mvp/queue/upsert-imdb-person` #12871

Role: Sole writer for `queue_imdb_person`. Idempotent upsert keyed on `imdb_url`: bump count + promote tier (debounced) + backfill `imdb_person_id` on repeat; full insert with source provenance on first sight.

Inputs:

| Name | Type | Req | Default | Xano default semantic | Go semantic |
|---|---|---|---|---|---|
| imdb_url | text | yes | — | trim; dedup key | `string`, trimmed |
| name | text | no | null | none | `*string`, insert-only |
| imdb_person_id | int | no | 0 | none, lambda-level `first_notempty` on backfill | `*int`; 0 must not overwrite a real existing id (see below) |
| cascade_depth | int | no | 0 | none, re-clamped in lambda (`finite && >0` else 0) | `int`, clamp in Go |
| priority_tier | int | no | `-1` sentinel | none; lambda: explicit `>=0` → `min(t,4)` else 4 | `*int`; nil ⇒ floor tier 4 |
| source_function | text | no | null | none, trim | `*string`, insert-only |
| source_entity_id | int | no | 0 | none | `*int`, insert-only |
| source_entity_type | text | no | null | none, trim | `*string`, insert-only |
| seed_imdb_person_id | int | no | 0 | none, passthrough | `*int` |
| seed_film_tv_id | int | no | 0 | none, passthrough | `*int` |

Output shape:
```json
{"action":"skipped_no_url","queue_id":null,"count":0}
{"action":"updated","queue_id":1,"count":3}
{"action":"inserted","queue_id":1,"count":1}
```

Reads: `queue_imdb_person` by `imdb_url` (id, count, priority_tier, imdb_person_id, last_promoted_at).
Writes: `db.edit` (update path) or `db.add` (insert path, `processing:false, count:1, last_promoted_at:now`).
Calls: none — leaf, all logic inline.
Idempotency key: `imdb_url` (natural key). Live drain task `159 process-queue-imdb-person` is **INACTIVE** per the manifest — queued rows accumulate but are not currently auto-drained; flag for the Go rebuild's rollout plan.

```go
	tierFloorUnlinked = 3

	"sag", "pga", "dga", "wga", "critics choice", "cannes", "venice", "berlin",
	"sundance", "peabody", "grammy", "tony", "independent spirit", "gotham"}

func UpsertAwardGraphQueue(ctx context.Context, in Input) (Output, error) {
	existing := db.Get(queueAwardGraph, WhereFilmTvAwardID(in.FilmTvAwardID))

	safeFilmTvID := 0
	switch {
	case valOrZero(in.FilmTvID) > 0:
		safeFilmTvID = valOrZero(in.FilmTvID)
	case existing != nil && existing.FilmTvID > 0:
		safeFilmTvID = existing.FilmTvID
	default:
		if row := db.Get(filmTVAward, in.FilmTvAwardID); row != nil && row.FilmTvID > 0 {
			safeFilmTvID = row.FilmTvID
		}
	}

	awardTier := 3
	if safeFilmTvID > 0 {
		rows := db.Query(filmTVAward, WhereFilmTvID(safeFilmTvID))
		switch {
		case hasPrestigeWin(rows, prestigeAwards) || len(rows) >= 3:
			awardTier = 1
		case len(rows) >= 1:
			awardTier = 2
		default:
			awardTier = 3
		}
	}

	pairTier := 3
	if safeFilmTvID > 0 {
		pairTier = awardTier
		if titleQ := db.Get(queueTitle, WhereFilmTvID(safeFilmTvID)); titleQ != nil {
			pairTier = min(awardTier, titleQ.PriorityTier)
		}
	}

	if safeFilmTvID <= 0 && requestedTierIsUrgent(in.PriorityTier) {
		logCrash(ctx, "caller_shape_mismatch_tripwire", Fields{"phase": "awards", "qa_passed": true})
	}

	floorIfUnlinked := func(v int) int {
		if safeFilmTvID <= 0 {
			return max(v, tierFloorUnlinked)
		}
		return v
	}

	var effectiveTier int
	var result Output

	switch {
	case valOrZero(in.RefreshMaterialized) > 0:
		// absolute precedence: reopens ONLY status/processing/attempt_count/next_attempt_at/last_error
		db.Edit(queueAwardGraph, existing.ID, ReopenFields{Status: "pending", Processing: false})
		result = Output{Action: "refresh_requeued", QueueID: existing.ID}
		effectiveTier = existing.PriorityTier

	case existing == nil:
		seedTier := floorIfUnlinked(pairTier)
		if in.PriorityTier != nil && *in.PriorityTier >= 0 {
			seedTier = floorIfUnlinked(min(*in.PriorityTier, 4))
		}
		row := db.Insert(queueAwardGraph, NewQueueRow{
			FilmTvAwardID: in.FilmTvAwardID, Status: "pending", PriorityTier: seedTier,
			LastPromotedAt: now(), Count: 1, AttemptCount: 0, MaxAttempts: 3,
		})
		result = Output{Action: "inserted", QueueID: row.ID}
		effectiveTier = min(pairTier, seedTier)

	case existing.Status == "success":
		result = Output{Action: "already_success", QueueID: existing.ID}
		effectiveTier = existing.PriorityTier

	case existing.Processing:
		result = Output{Action: "already_processing", QueueID: existing.ID}
		effectiveTier = existing.PriorityTier

	default:
		mayPromote := time.Since(existing.LastPromotedAt) > windowMS*time.Millisecond
		base := existing.PriorityTier
		if base < 0 {
			base = 4
		}
		dec := base
		if mayPromote {
			dec = max(0, base-1)
		}
		promotedTier := dec
		if in.PriorityTier != nil && *in.PriorityTier >= 0 {
			promotedTier = max(0, min(dec, min(*in.PriorityTier, 4)))
		}
		promotedTier = floorIfUnlinked(promotedTier)
		lastPromotedAt := existing.LastPromotedAt
		if mayPromote && promotedTier < base {
			lastPromotedAt = now()
		}
		db.Edit(queueAwardGraph, existing.ID, RequeueFields{
			Status: "pending", PriorityTier: promotedTier,
			LastPromotedAt: lastPromotedAt, Count: existing.Count + 1,
		})
		result = Output{Action: "requeued", QueueID: existing.ID}
		effectiveTier = min(pairTier, promotedTier)
	}

	effectiveTier = clamp(effectiveTier, 0, 4)

	if titleQ := db.Get(queueTitle, WhereFilmTvID(safeFilmTvID)); titleQ != nil && effectiveTier < titleQ.PriorityTier {
		db.Edit(queueTitle, titleQ.ID, TierUpdate{PriorityTier: effectiveTier}) // promote-only

	for _, sib := range db.Query(queueAwardGraph, WhereFilmTvID(safeFilmTvID), WhereTierGreaterThan(effectiveTier)) {
		db.Edit(queueAwardGraph, sib.ID, TierUpdate{
			PriorityTier: effectiveTier, PromotionSource: "sibling_notability_propagation",
		}) // promote-only
	}

	result.Status = "pending"
	return result, nil
}
```

Calls: `add-node-edge-imdb-award` #2334 (per row, wrapped in `try_catch`, followed by a `precondition` requiring a non-empty `node_uuid` readback).

Retry/timeout/failure behavior: per-row `try_catch`; one row's failure never stops the batch.

```go
func ProcessAwardGraphBatch(ctx context.Context, in Input) (Output, error) {
	queueID := valOrZero(in.QueueID)
	scopePersonID := valOrZero(in.ImdbPersonID)
	limit := clamp(firstNotEmpty(in.Limit, 10), 1, 20)

	var items []QueueRow
	switch {
	case queueID > 0:
		items = db.Query(queueAwardGraph, WhereID(queueID), WhereProcessing(false), WhereStatusNot("success"))
	case scopePersonID > 0:
		items = db.QueryPaged(queueAwardGraph,
			WhereImdbPersonID(scopePersonID), WhereProcessing(false),
			WhereStatusIn("pending", "error"), WhereAttemptLT("max_attempts"),
			OrderBy("priority_tier asc, cascade_depth asc, id asc"), limit)
	default:
		items = db.QueryPaged(queueAwardGraph,
			WhereProcessing(false), WhereStatusIn("pending", "error"), WhereAttemptLT("max_attempts"),
			OrderBy("priority_tier asc, cascade_depth asc, id asc"), limit)
	}

	processed, errored := 0, 0
	var processedIDs []int

	for _, row := range items {
		attemptNumber := row.AttemptCount + 1
		leaseToken := uuid.New()
		db.Edit(queueAwardGraph, row.ID, LeaseFields{
			Status: "processing", Processing: true, AttemptCount: attemptNumber,
			LastAttemptAt: now(), LeaseToken: leaseToken,
			LeaseExpiresAt: now().Add(300 * time.Second), LastError: nil,
		})

		err := func() (err error) {
			defer func() {
				if r := recover(); r != nil {
					err = fmt.Errorf("%v", r)
				}
			}()
			AddNodeEdgeIMDbAward(ctx, row.FilmTvAwardID, AwardEdgeOpts{}) // #2334
			award := db.Get(filmTVAward, row.FilmTvAwardID)
			if award == nil || award.NodeUUID == "" {
				return errors.New("IMDb award graph writer returned without a node UUID")
			}
			db.Edit(queueAwardGraph, row.ID, SuccessFields{
				Status: "success", CompletedAt: now(), AwardNodeUUID: award.NodeUUID,
				Result: map[string]any{"writer": "add-node-edge-imdb-award", "film_tv_award_id": row.FilmTvAwardID, "node_uuid": award.NodeUUID},
			})
			return nil
		}()

		if err != nil {
			db.Edit(queueAwardGraph, row.ID, FailureFields{
				Status: "error", LastError: err.Error(), NextAttemptAt: now().Add(60 * time.Second),
			})
			errored++
			if attemptNumber < 3 { // max_attempts
				logCrash(ctx, "retryable", Fields{"phase": "awards", "qa_passed": true})
			} else {
				logCrash(ctx, "exhausted", Fields{"phase": "awards", "qa_passed": false, "error_message": err.Error()})
			}
			continue
		}
		processed++
		processedIDs = append(processedIDs, row.ID)
	}

	return Output{Action: "batch_completed", Selected: len(items), Processed: processed, Errors: errored, ProcessedQueueIDs: processedIDs}, nil
}
```

- Retryable-vs-exhausted `log_crash` coloring by `attemptNumber` vs. `max_attempts` — `Preserve for parity`; matches the cross-pipeline #13199/#12992 doctrine.

```go
	func() { defer recoverLog(ctx, "credit_edges"); AddCreditEdgesFromTitle(ctx, title.ID) }() // #13015

	func() { // "awards" — benign-race string-match swallow (Duplicate record detected)
		defer func() {
```

```go
const (
	depthCap = 3
	t3Keep   = 20
)

func CascadeCreditsFromPerson(ctx context.Context, in Input) (Output, error) {
	person := db.Get(imdbPerson, in.IMDbPersonID, Fields{"id", "name", "json"})
	if person == nil {
		return Output{Action: "skipped_no_person"}, nil
	}
	credits := person.JSON.Credits
	if len(credits) == 0 {
		return Output{Action: "no_credits"}, nil
	}

	depth := valOrZero(in.CascadeDepth)
	nextDepth := depth + 1
	seedPersonID := firstNotEmpty(in.SeedIMDbPersonID, in.IMDbPersonID)
	if nextDepth >= depthCap {
		return Output{Action: "depth_exceeded", Cascaded: 0}, nil
	}

	var tiered []TieredCredit
	for _, c := range credits {
		if c.IMDbURL == "" {
			continue // dropped, not tiered, not counted
		}
		tier := tierByRatingAndRecency(c.Rating, c.Year) // T1 rating>=8.0, T2 >=7.0, T3 (yearsAgo<=3 || rating>=6.0), else T4
		if isWeakFormat(c.Type) {
			tier = min(4, tier+1)
		}
		if isMinorRole(c.Roles) {
			tier = min(4, tier+1)
		}
		tiered = append(tiered, TieredCredit{Credit: c, Tier: tier, AboveTheLine: computeATL(c.Roles)}) // AboveTheLine unused downstream
	}
	demoteT3Overflow(tiered, t3Keep) // sort T3 by rating desc; overflow past 20 -> T4, mark _demoted_overflow, never dropped

	syncedCount := 0
	syncTopN := valOrZero(in.SyncTopCredits)
	isDepthZero := depth == 0 // pre-increment depth, not nextDepth
	if syncTopN > 0 && isDepthZero && len(tiered) > 0 {
		byTierThenRating(tiered) // sort tier ASC, rating DESC
		for i := 0; i < min(syncTopN, len(tiered)); i++ {
			tiered[i].Sync = true
		}
	}

	cascaded := 0
	for _, tc := range tiered {
		func() {
			defer func() {
				if r := recover(); r != nil {
					logCrash(ctx, "credit_edges_cascade", Fields{"error_message": fmt.Sprint(r), "priority_tier": tc.Tier})
				}
			}()
			req := GetAddTitleInput{
				IMDbURL: tc.Credit.IMDbURL, Title: tc.Credit.Title, CascadeDepth: nextDepth,
				PriorityTier: tc.Tier, SourceFunction: "cascade-credits-from-person",
				SourceEntityID: in.IMDbPersonID, SourceEntityType: "imdb_person", SeedIMDbPersonID: seedPersonID,
			}
			if tc.Sync {
				req.Queue = boolPtr(false) // synchronous, preserves nextDepth (not forced to 0)
				GetAddIMDbTitle(ctx, req)
				syncedCount++
			} else {
				req.Queue = boolPtr(true)
				GetAddIMDbTitle(ctx, req)
			}
			cascaded++
		}()
	}

	return Output{Action: "cascaded", NextDepth: nextDepth, Cascaded: cascaded, SyncEnriched: syncedCount, TotalCredits: len(credits), KeptAfterTiering: len(tiered)}, nil
}
```

```go
	person := db.Get(imdbPerson, in.IMDbPersonID, Fields{"id", "node_uuid", "imdb_url", "name", "master_person_id"})
	if person == nil || person.IMDbURL == "" {
		return Output{Action: "skipped_no_person"}, nil
	}

	awardURL := rtrimSlash(person.IMDbURL) + "/awards"
	scrape, _ := FirecrawlScrape(ctx, ScrapeReq{URL: awardURL, SoftFail: true, Caller: "add-award-records-from-imdb-person"}) // #4515
	if scrape.Markdown == "" {
		logCrash(ctx, "skip", Fields{"qa_passed": true, "error_message": ""})
		return Output{Action: "skipped_no_awards_markdown", AwardURL: awardURL}, nil
	}

	clean := stripIMDbBoilerplate(scrape.Markdown)
	if matchesNoAwardsPhrase(clean) { // 6 literal phrases
		db.Edit(imdbPerson, person.ID, AwardsSave{AwardMarkdown: clean, AwardsJSON: []any{}})
		return Output{Action: "no_awards", AwardRows: 0}, nil
	}

	var awards []map[string]any
	func() {
		defer func() {
			if r := recover(); r != nil {
				logCrash(ctx, "llm_parse", Fields{"error_message": fmt.Sprint(r)})
				awards = nil
			}
		}()
		resp, _ := openrouterChat(ctx, ChatReq{
			Model: "google/gemini-3.1-flash-lite", Temperature: 0, MaxTokens: 65536,
			Messages: []Msg{{Role: "system", Content: renderPersonAwardsPrompt(clean)}},
			DataCollection: "deny", Timeout: 300 * time.Second,
		})
		raw := cleanAndParseJSON(resp) // strip fences, JSON.parse
		raw = salvageArray(raw)        // truncated-JSON repair
		raw = coerceSevenFieldShape(raw)
		awards = CleanMyJSON2(raw).([]map[string]any) // #2806
	}()

	db.Edit(imdbPerson, person.ID, AwardsSave{AwardMarkdown: clean, AwardsJSON: awards}) // try/catch, log+continue

	if len(awards) == 0 {
		logCrash(ctx, "zero_awards_warn", Fields{"qa_passed": true})
	}

	inserted, upgraded, duplicateSkipped := 0, 0, 0
	var upgradedAwardIDs []int
	upgradedInlineCount := 0

	for _, a := range awards {
		func() {
			defer func() { recover() }() // per-award try/catch, continue on error
			filmTVID := 0
			if url := coerceTitleURL(a["project_imdb_url"]); url != "" && nextDepthOf(in.CascadeDepth) < 3 {
				resolved := GetAddIMDbTitle(ctx, GetAddTitleInput{
					IMDbURL: url, Queue: boolPtr(true), PriorityTier: intPtr(2),
					CascadeDepth: valOrZero(in.CascadeDepth),
				}) // #12874
				filmTVID = resolved.FilmTVID
			}
			result := ResolveUpsertAward(ctx, ResolveAwardInput{ // #13246
				FilmTVID: filmTVID, IMDbPersonID: person.ID, Year: coerceYear(a["year"]),
				AwardType: strVal(a["award_type"]), AwardDescription: strVal(a["award_description"]),
				NomineeOrWinner: strVal(a["nominee_or_winner"]), ProjectTitle: strVal(a["project_title"]),
				ProjectIMDbURL: strVal(a["project_imdb_url"]),
			})
			switch result.Action {
			case "inserted":
				inserted++
			case "upgraded_sparse":
				upgraded++
				upgradedAwardIDs = append(upgradedAwardIDs, result.FilmTVAward.ID)
			default:
				duplicateSkipped++
			}

			if result.Action == "inserted" || result.Action == "upgraded_sparse" {
				if upgradedInlineCount < 10 {
					if err := tryAddNodeEdgeAward(ctx, result.FilmTVAward.ID); err == nil { // #2334, skip_embedding:true
						upgradedInlineCount++
						return
					}
				}
				UpsertAwardGraphQueue(ctx, QueueRepairInput{ // priority_tier OMITTED intentionally
					FilmTVAwardID: result.FilmTVAward.ID, CascadeDepth: valOrZero(in.CascadeDepth),
					SourceFunction: "add-award-records-from-imdb-person:upgraded_sparse",
				})
			}
		}()
	}

	remainingInlineLimit := 10 - upgradedInlineCount
	if remainingInlineLimit > 0 {
		BackfillAwardEdgesIMDb(ctx, BackfillInput{ // #13014
			IMDbPersonID: person.ID, Limit: remainingInlineLimit, OnlyMissing: true,
		})
	}
	for _, row := range db.Query(filmTVAward, WhereIMDbPersonID(person.ID), WhereNodeUUIDNull(), OrderBy("id asc")) {
		UpsertAwardGraphQueue(ctx, QueueSweepInput{ // priority_tier:3 explicit
			FilmTVAwardID: row.ID, PriorityTier: 3, CascadeDepth: valOrZero(in.CascadeDepth),
			SourceFunction: "add-award-records-from-imdb-person",
		})
	}
	logCrash(ctx, "award_graph_materialized_or_queued", Fields{"qa_passed": true})

	return Output{
		Action: "awards_extracted", AwardRows: len(awards), Inserted: inserted, Upgraded: upgraded,
		UpgradedAwardIDs: upgradedAwardIDs, Skipped: len(awards) - inserted - upgraded,
		DuplicateSkipped: duplicateSkipped,
	}, nil
}
```

### `mvp/falkor/send-cypher` #2815

Role: Shared FalkorDB Cypher execution transport. Loads connection credentials from the `environmental_variables_falkordb` singleton row (id=1), executes via `npm:falkordb` with per-attempt fresh connections, retry/backoff, and manual timeout races, returns the raw driver result. Calls: none — leaf transport.
Idempotency key: n/a — MERGE-key idempotency is entirely the caller's responsibility.

Fresh connection per attempt (`connectTimeout:10000ms` hardcoded), ping race (`5000ms`), query race (`timeout_ms` input). Every error class — including a genuine Cypher syntax error — gets the same 3-attempt retry treatment.

Artifact decisions:
- **The string-on-failure transport contract is the highest-leverage decision in this whole spec** — 5+ of the other functions in this batch depend on it, several with zero error handling of their own. - `connectTimeout` hardcoded at 10000ms, not influenced by `timeout_ms` — `Preserve for parity`.
- None of the 4 write-functions in this batch use native `params` placeholders — every one string-builds Cypher via JS template literals with inline `JSON.stringify`'d literals — `Xano artifact — do not reimplement`; Go should parameterize, replicate current behavior first for parity.

Acceptance checks:
- A malformed Cypher query still returns within ~3s×3 attempts (no infinite hang) and produces the documented string/degraded-result shape.
- `environmental_variables_falkordb` (id=1) is added to the Go rebuild's dependency/config inventory even though it's absent from the manifest's table list.

Open questions: see the transport-contract decision above — this is the single biggest open decision blocking a faithful Go port of the whole graph-write surface.

```go
	url := strings.TrimSpace(in.IMDbPersonURL)
	if url == "" {
		return "", nil
	}

	// phase 2: canonicalize identity — UNCAUGHT precondition on cross-person collision
	nmID, _ := extractNmID(url)
	canonicalURL := canonicalizeOrFallback(url, nmID)
	byURL := db.Get(imdbPerson, WhereIMDbURLEquals(canonicalURL))
	ownedRows := db.Query(imdbPerson, WhereMasterPersonID(in.MasterPersonID))
	existing := pickBestCrossVariant(byURL, ownedRows) // verified > has-node_uuid > oldest id
	if existing != nil && existing.MasterPersonID != 0 && existing.MasterPersonID != in.MasterPersonID {
		panic("imdb identity already owned by a different master_person") // fail-closed, no try_catch here
	}
	if existing == nil {
		mp := db.Get(masterPerson, in.MasterPersonID, Fields{"full_name"})
		existing = db.Insert(imdbPerson, StubRow{IMDbURL: canonicalURL, Name: mp.FullName})
	} else if existing.MasterPersonID == 0 {
		db.Edit(imdbPerson, existing.ID, LinkEdit{MasterPersonID: in.MasterPersonID})
	}

	// phase 3: staleness
	needsScrape := existing.EnrichedAt.IsZero() || time.Since(existing.EnrichedAt) >= 30*24*time.Hour

	// phase 4: scrape or skip
	if !needsScrape {
		db.Edit(imdbPerson, existing.ID, ResetEdit{CascadeDepth: 0, EnrichSuccess: false})
	} else {
		scrape, err := FirecrawlScrape(ctx, ScrapeReq{URL: canonicalURL, SoftFail: true}) // #4515

			UpsertIMDbPersonQueue(ctx, QueueInput{ // #12871
				IMDbURL: canonicalURL, PriorityTier: 1, CascadeDepth: 0,
				SourceFunction: "add-imdb-to-master-person", SourceEntityType: "master_person",
			})
			return existing, nil // Firecrawl-miss: unchanged row, retry queued
		}
		var extracted map[string]any
		func() {
			defer recoverLog(ctx, "llm_extract_crash")
			resp, _ := openrouterChat(ctx, ChatReq{
				Model: "google/gemini-3.1-flash-lite", Temperature: 0, MaxTokens: 16384,

			})
			raw := jsonParseFenced(resp) // strip fences, validate leading {/[, JSON.parse — throws on failure

		}()

			return "", nil // scrape/LLM crash
		}
		if strVal(extracted["name"]) == "" {
			return map[string]any{"error": "no usable name extracted", "imdb_url": canonicalURL}, nil
		}

	}

			continue
		}

			URL: site.URL, MasterPersonID: in.MasterPersonID, Source: "IMDb", SuppressDownstream: suppress,
		})
	}

		defer func() {

				dateProjectionVerified = false
				logCrash(ctx, "imdb_date_projection", Fields{"qa_passed": false})
			}
		}()

		ProjectMasterDates(ctx, in.MasterPersonID)
		readback := readMasterAndEnrichmentDates(ctx, in.MasterPersonID)
		if !exactParity(readback) {
			panic("IMDb master-date projection parity failed")
		}
	}()

		defer recoverLog(ctx, "IMDB person enrichment")
		AddPersonBiography(ctx, in.MasterPersonID, person.JSON.Biography, "IMDb") // #2536
		AddRoles(ctx, in.MasterPersonID, person.JSON.Professions)                 // #10510
		CreateLLMPersonBios(ctx, in.MasterPersonID)                              // #2537
		UpdatePersonNode(ctx, in.MasterPersonID)                                 // #2758

		EnrichedAt: now(), CascadeDepth: 0, EnrichSuccess: true, Verified: true,

	}) // only place enrich_success becomes true

	return db.Get(imdbPerson, person.ID), nil
```

### Firecrawl v2 /scrape (via `mvp/firecrawl/scrape` #4515)

Called by: #12880, #12881, #12887, #12879, #10509 (all via #4515).
Purpose: fetch a rendered IMDb page (person profile, title profile, `/awards/` sub-pages) as markdown for LLM extraction.

```http

Authorization: Bearer <FIRECRAWL_API_KEY>
```

```json
{
  "url": "https://www.imdb.com/name/nm0000001",
```

### FalkorDB transport (via `mvp/falkor/send-cypher` #2815)

Called by: nearly every graph-writing function in this pipeline (#2320, #2334, #2601, #2758, #13013, #13015, #13016, #13017, #13020, #13142, #12926, #13141's own roster fetch, and more) — the single graph transport for the whole waterfall.
Purpose: execute an arbitrary Cypher query/mutation against the FalkorDB graph.

Request (conceptual — direct TCP/socket driver, not HTTP):
```
FalkorDB.connect({
  username, password,
  socket: { host, port, connectTimeout: 10000, commandTimeout: <timeout_ms input>,
            reconnectStrategy: retries>2 ? stop : min(retries*500, 2000) }
})
graph.query('RETURN 1')                    // ping, race vs 5000ms
graph.query(cypher_query[, {params}])      // real query, race vs timeout_ms (default 30000)
```

Auth: `username`/`password` loaded from the `environmental_variables_falkordb` singleton row (id=1) — **undocumented in the manifest's table list**, add it to the Go rebuild's config inventory. Header/credential NAMES only — values never logged; the lambda redacts embedded `vecf32([...])` vector literals from its `console.log` output via regex but does NOT redact any other interpolated text before logging the full query string on every attempt.
Timeout: `connectTimeout` hardcoded 10000ms (not influenced by the `timeout_ms` input); ping race 5000ms hardcoded; query race = `timeout_ms` input, default 30000ms.
Retries/backoff: `maxRetries=3` hardcoded, exponential backoff `1000 * 2^(attempt-1)` = 1000ms after attempt 1, 2000ms after attempt 2, no wait after attempt 3 (throws immediately). Fresh connection opened per attempt — no pooling/reuse, even on a successful first attempt.
Terminal statuses: **on unrecoverable failure (all 3 retries exhausted), the function returns a STRING, not a XanoScript throw** — even though the underlying JS literally executes `throw error` after retry exhaustion. This is the single highest-leverage transport-contract detail in the whole pipeline (see section 8's #2815 sheet for the full blast-radius list of unguarded callers).
Response fields consumed: callers read `r.data` (array of rows, positional-array or keyed-object depending on the `RETURN` clause) or fall back to `r.result`.
Raw payload persistence: none — no `log_crash` writes inside #2815 itself; all internal diagnostics are `console.log` only.
Replay fixture required: yes, and this is the highest-value fixture in the whole graph layer — capture (a) a successful query result shape, (b) a 0-row MATCH result shape, and (c) the exact string returned after 3-retry exhaustion, so every downstream caller's degrade-to-string handling can be exercised in Go without a live FalkorDB instance.
Go client notes: this is THE open architectural decision for the graph layer (see section 8's #2815 open question) — decide once, apply everywhere: either preserve the string-sentinel contract for parity with today's silently-degrading callers, or return idiomatic Go `error`s and audit every one of the ~15+ call sites that currently have zero error handling around this dependency. None of the callers in this pipeline use FalkorDB's native parameterized-query mechanism (`params`) — every one string-builds Cypher via template literals with inline `JSON.stringify`'d values instead; replicate current behavior first for parity, treat native params as a follow-up improvement.

### Per-call notes (subtle behavior only)

**#2537 — disabled short-bio prompt (the highest-severity quirk in this table).** The block that builds the correct 229-char short-bio prompt is written with a leading `!` (Xano's disabled-step syntax, same convention as `!debug.stop`) — it never actually runs. Immediately after, an ENABLED `util.template_engine` block overwrites `$systemPrompt` with the 500-char / 1–2-line-break LONG-bio prompt text. The OpenRouter call labeled "short bio" therefore runs against the long-bio prompt's constraints, not the intended single-sentence 229-char constraint — the primary generation path for the short bio is effectively generating long-bio-shaped content. Downstream code still applies the 229-char sentence-boundary fallback trimmer if the result is empty, which partially masks the effect. This is `Preserve for parity` for a byte-identical rebuild of the LIVE behavior, but is very likely an unintentional regression and is flagged as `Open question for Mark` for a product fix decision before the Go rebuild ships it as-is.

**#12879 — deterministic-parse-first + LLM-cleanup-only with a row-count floor.** Unlike #12887 (LLM does the primary extraction), #12879 deterministically regex-parses every visible Winner/Nominee line from the scraped markdown FIRST, then uses the LLM purely to normalize/clean that already-correct row set. Two hallucination guards: (1) if the LLM's cleaned JSON has FEWER rows than the deterministic parse produced, `$awards` reverts entirely to the deterministic set — the LLM can never reduce the row count; (2) if the LLM response is empty, the deterministic JSON is substituted directly with no second HTTP call (despite historical changelog wording describing a "retry" — current code does not retry). This is `Preserve for parity` end to end; the one `Fix in Go` item is a redundant duplicate zero-length check left over from that stale retry logic.

**#12881 (via #13182) — the `usable` gate.** `#13182`'s `usable` boolean — not an LLM parameter itself, but the gate that decides whether #12881's LLM extraction is trusted — requires `title present AND (hasContent [any of plot/year/genres/directors/writers/type] OR (hasIdentity [title + (imdb_title_id OR imdb_url)] AND hasAwardsSummary))`. A `usable:false` result routes #12881 to its stub-node fallback path rather than a full save, regardless of whether the underlying LLM call itself technically "succeeded" (returned 200 with SOME JSON). This decouples "the LLM responded" from "the LLM response is usable," which is why #12881's own `llm_extract` phase has a 3-way outcome (usable, sparse-benign, hard-failure) rather than a simple success/fail.

**#12666 — two independent digest gates.** An input-digest (`sha256({model, context})`) skips the ENTIRE LLM call when unchanged AND relational/graph mirrors already exist. A separate signals-digest (`sha256` of the parsed signal array) skips the downstream resolve/dual-write (#12926) when a FRESH LLM call reproduces byte-identical signals to the last run — the LLM still ran in this case, only the expensive graph/relational write is skipped. Both gates require existing mirrors (`person_has_expertise` count > 0) to fire; a person with zero prior expertise rows always runs the full pipeline regardless of digest match. Both are `Preserve for parity`.

**#10516 — missing `:online` suffix.** The v4 changelog claims the model string retains a `:online` OpenRouter routing suffix "for web-search grounding," but the LIVE `$model` variable has no such suffix — web-search grounding is NOT actually active for tagline generation today, contradicting the changelog's stated intent. Code is authoritative per the extraction brief; flagged as `Open question for Mark` — confirm whether grounding should be restored (add `:online`) or the changelog comment corrected before porting to Go.

## 13. Queue and Worker Contract

### Upsert semantics (all three queues — `Preserve for parity`)

- Sole-writer rule: exactly one function writes each queue (`#12871`, `#12872`, `#13244`). Grep before adding writers; the 2026-07-25/26 incident class came from second writers.
- Insert: tier clamped to 0–4 (explicit 0 preserved — `first_notnull` semantics), `last_promoted_at` stamped at INSERT so the first mechanical re-add cannot promote.
- Duplicate: `count++`; promotion `dec = now - last_promoted_at > 30min ? max(0, cur - 1) : cur`; explicit incoming tier: `max(0, min(dec, incoming))`.
- `#12872` additionally equalizes symmetrically with sibling award rows: shared tier = `min(title, all its awards)`, written to both sides.
- `#13244` enforces a structural tier ≥ 3 floor for unlinked awards at four independent points, plus a caller-shape tripwire. (`#13246`'s writer-side refresh copy uses floor 4 — `Open question for Mark`.)

### Workers

| Queue | Worker | Live state | Pick | Lock | Failure |
| --- | --- | --- | --- | --- | --- |
| #706 | Task 159 (inline stack) | INACTIVE, 600 s | `processing=false`, order tier/depth/id asc, ALL tiers | `processing=true` | release lock, retry next tick; missing-stub → log + delete row |
| #707 | Task 160 | INACTIVE, 600 s | same | same | same |
| #764 | Task 191 → `#13245` | **ACTIVE**, 60 s × limit 20 | pending rows | 5-min lease + 3 attempts (fields written; own selection doesn't re-check them — see Section 22) | green/red telemetry split; park on exhaustion |

Go worker shape:

```sql
SELECT * FROM universe.queue_imdb_person
WHERE processing = FALSE
ORDER BY priority_tier ASC, cascade_depth ASC, id ASC
LIMIT 1
FOR UPDATE SKIP LOCKED;
```

Processing transaction: claim → dispatch orchestrator OUTSIDE the row transaction (enrichment is minutes-long; hold a lease, not a row lock) → delete on success / release + `attempts++` on failure → DLQ (park) after N attempts with a loud log. Explicit-zero: a `priority_tier: 0` row is picked first and must never be re-coerced. Record: person/title crons ship INACTIVE — the frozen contract includes "the queues do not drain unless someone flips them"; the award-graph drain ships ACTIVE.

### Film_TV_Award node + HAS_AWARD / WON_AWARD / NOMINATED_FOR edges

MERGE key: none — both writers do a `db.query node_registry where node_uuid==X (return type:"exists")` THEN a conditional `db.add` if not present. This is check-then-add, **not an atomic MERGE**; a race could theoretically double-insert.
Required properties: `created_at`, `node_uuid`, and the literal (misspelled) column `entitiy_type`.
Null/empty omission rules: n/a — always a full insert.
Timestamps: `created_at` only, insert-time.
Weight/Description/Embedding fields: n/a — this is a lightweight registry row, not a graph entity.
Idempotency behavior: check-then-add, non-atomic. Both #2320 and #2334's writes are non-aborting on failure (logged, function continues) — this registration is best-effort bookkeeping, not load-bearing for the graph write itself.
Cypher source: n/a — pure relational `db.query`/`db.add`, no Cypher involved.
Go helper shape:
```go

	NodeUUID   string
	EntityType string // column is literally "entitiy_type" in the live schema

```
Go graph helper notes: `entitiy_type` is a **literal misspelling used consistently across every writer** — `Xano artifact — do not reimplement`; preserve verbatim in any compatibility layer that reads the legacy table, but the Go rebuild's own AlloyDB/registry schema should use the correctly-spelled column name and is free to add a real unique constraint on `node_uuid` to close the check-then-add race — confirm with Mark whether `node_registry` carries a live unique constraint TODAY before assuming the race is purely theoretical (`Open question for Mark`, carried forward from section 8's #2334 sheet).

## 17. Error Handling and Observability

- **Phase envelope:** every orchestrator phase writes one structured event (Xano: `log_crash` row). Contract: `phase` from a fixed enum per pipeline, `qa_passed` boolean, `error_message` empty ⇒ telemetry (green), non-empty ⇒ genuine failure (red). **Never count rows as a health signal — filter on non-empty `error_message`/severity** (the table is an audit log, not a crash log).
- **Continuation rules:** P2/P3/P4a abort person enrichment; P4b/P4c/P5/P6 log-and-continue; cascade helpers wrap every child `get-add` in try/catch — one bad child never kills a run.
- **Kill switches:** `check-kill-switch-imdb` #12870 (imdb-family row-count threshold, env-driven) and `check-kill-switch-v2` #4617 (master-person mint breaker, threshold in an `environment_variables` row). Both fail-open on internal error — `Preserve for parity`, but surface a metric when the switch itself errors.
- **Graph write failures are currently near-silent** (string-error transport + unchecked SETs in #2320/#13017 and the #13013 fake-`completed` swallow). In Go: every graph write returns an error; call sites keep their documented abort/continue behavior but ALWAYS emit the failure metric. This is a sanctioned `Fix in Go` (observability only — control flow unchanged).
- Go observability: structured logs keyed by `run_id`/entity, counters per phase outcome, and the fixture harness asserting the green/red split.

## 19. Acceptance Checks

### Contract checks
- Given `{imdb_url, cascade_depth:0, queue:false}`, the gate returns `enriched_direct` with the entity ids; the same input again returns `existing` inside the freshness window.
- Duplicate discovery of the same URL never creates a second queue row; `count` increments; promotion respects the 30-minute debounce; an explicitly lower tier wins immediately.
- Explicit `priority_tier: 0` and `cascade_depth: 0` survive every layer (gate → upsert → worker) unchanged.
- Unlinked award jobs cannot enter below tier 3.

### Provider replay checks
- With frozen fixtures, the Firecrawl/Serper/Exa/OpenRouter clients consume recorded payloads and produce identical normalized structs; `soft_fail` awards scrapes skip cleanly on empty markdown.

### Graph checks
- Re-run duplicates nothing MERGE-keyed; `created_at` stable, `updated_at` moves; co-nominees converge on ONE award node with N person edges; honorary awards MERGE per-person.
- Empty/null optional properties are absent — never empty strings or nulls.
- Every `WORKED_ON` edge has weight 30, a uuid, and a description stamped at write time.

### Queue checks
- Person/title workers pick by tier/depth/id and release the lock on failure; a missing-stub row is logged and deleted, never retried forever.
- Award worker processes ≤20/tick; a poisoned job parks after 3 attempts with a red log; the queue drains to zero on the fixture set.

### Projection checks
- Title display row exists after node write (thin) and carries poster/tagline after P7; `run_id` replay is a no-op.

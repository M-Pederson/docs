## The model

Files are `:Document` **stub nodes** — id + name + mime + a short generated description; **bytes live in GCS**, metadata in AlloyDB, extracted text chunked into the shared files search index. Provenance is legible in the edge type: `UPLOADED` = the user placed it; `SAVED` = the system captured it from an interaction. Full flows on [Edge Sync → Files](/guides/open-work/edge-sync#files).

## Edge and node properties

**Document node:** `doc_id` · `name` · `mime` · `description` (generated) · `origin: manual | email` · `content_hash` · `created_at` / `updated_at`

| Edge | Direction | Properties | Weight |
|---|---|---|---|
| `UPLOADED` | User → Document | `uuid`, `source: "manual"`, `uploaded_at` | **None** |
| `SAVED` | User → Document | `uuid`, `source: "email_attachment"`, `interaction_id`, `saved_at` | **None** |
| `ATTACHED_TO` | Document → Person / Company | `uuid`, `via: "manual" \| "email_attachment"`, `attached_at` | **None** |

Content edges carry no weight (see the no-weight rule on the Notes page).

## Capture gates for SAVED *(launch defaults, tunable)*

- Sender must already be a **KNOWS contact** — attachments from unknown inbound senders save nothing, ever (the intent system again).
- Document-type mime allowlist (pdf, docx, xlsx, pptx, …); minimum size; no inline images.
- **Dedupe by `content_hash` per user** — a re-sent attachment creates no new node; a new `ATTACHED_TO` edge only if it arrives in the context of a different entity.

## Simulated examples

**1 — Mark uploads a pitch deck and attaches it to Knock.app** (manual-add intent fires first if Knock is absent):

```cypher
MERGE (d:Document {doc_id: $id})
  ON CREATE SET d.name = "knock-pitch.pdf", d.mime = "application/pdf",
                d.description = "Seed pitch deck, 18 slides, GTM focus",
                d.origin = "manual", d.content_hash = $hash, d.created_at = $now
MERGE (me)-[u:UPLOADED]->(d)
  ON CREATE SET u.uuid = randomUUID(), u.source = "manual", u.uploaded_at = $now
MERGE (d)-[a:ATTACHED_TO]->(:Company {uuid: $knock_uuid})
  ON CREATE SET a.uuid = randomUUID(), a.via = "manual", a.attached_at = $now
```

**2 — Sam Seely emails Mark `knock-overview.pdf`** (Sam is a KNOWS contact → gate passes; log-parse captures):

```cypher
MERGE (d:Document {doc_id: $id})
  ON CREATE SET d.name = "knock-overview.pdf", d.mime = "application/pdf",
                d.description = "Company overview one-pager",
                d.origin = "email", d.content_hash = $hash, d.created_at = $now
MERGE (me)-[s:SAVED]->(d)
  ON CREATE SET s.uuid = randomUUID(), s.source = "email_attachment",
                s.interaction_id = $interaction_id, s.saved_at = $now
MERGE (d)-[a:ATTACHED_TO]->(:Person {uuid: $sam_uuid})
  ON CREATE SET a.uuid = randomUUID(), a.via = "email_attachment", a.attached_at = $now
```

Sam re-sends the same file next week: `content_hash` matches → no new node, no new edges, `updated_at` refreshed.

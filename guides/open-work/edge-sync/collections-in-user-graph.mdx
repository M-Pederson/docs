## The model

`(User)-[:COLLECTED]->(Entity)` — the edge that lets **any Universe entity type** enter a user graph (a movie title puts a `Film_TV` node in the star). The Collection itself is an **AlloyDB construct** referenced by `collection_id` on the edge — one edge per membership — promotable to a graph node later if collections ever need graph-side identity (same judgment as Projects). `COLLECTED` **satisfies the star rule by itself**: it is the direct user edge; no FOLLOWS/KNOWS is implied or created.

**Collection sharing adds entities.** An entity arriving in a collection *shared with* the user is added to the user's graph (`source: "shared_collection"`) — the one receive-path that does add entities, in deliberate contrast to shared notes, whose subjects stay lazy.

## Properties

| Property | Value |
|---|---|
| `uuid` | Stable edge id |
| `collection_id` | The AlloyDB collection this membership belongs to |
| `added_at` | When the entity entered the collection |
| `source` | `"own"` \| `"shared_collection"` |
| `shared_by` | Sharer's user uuid (only when `source: "shared_collection"`) |
| `created_at` / `updated_at` | Epoch millis |
| **Weight** | **None** — and `COLLECTED` is **not a path anchor** (a collection can't make an introduction); it contributes context and ranking signals only |

## Simulated examples

**1 — Mark adds Anthropic to his own "AI targets" collection** (Anthropic already in his graph via FOLLOWS — the COLLECTED edge simply adds membership):

```cypher
MATCH (c:Company {uuid: $anthropic_uuid})
MERGE (me)-[m:COLLECTED {collection_id: $ai_targets_id}]->(c)
  ON CREATE SET m.uuid = randomUUID(), m.added_at = $now,
                m.source = "own", m.created_at = $now
SET m.updated_at = $now
```

**2 — A teammate shares a "Films about AI" collection with Mark; it contains *Her*** (a `Film_TV` entity nowhere in Mark's graph):

```cypher
MERGE (f:Film_TV:Entity {uuid: $her_uuid})          // stub created — any Universe type
MERGE (me)-[m:COLLECTED {collection_id: $films_id}]->(f)
  ON CREATE SET m.uuid = randomUUID(), m.added_at = $now,
                m.source = "shared_collection", m.shared_by = $teammate_uuid,
                m.created_at = $now
```

Mark's graph now contains a movie node — searchable in his scope, hydrated from Universe at read time, excluded from intro-path anchors.

## Lifecycle

Removing an entity from a collection deletes **that membership edge** (edges are per-collection). When an entity's **last** edge of any type disappears, the stub is garbage-collected — no orphan nodes in the star. Unsharing a collection removes all its `source: "shared_collection"` edges from the recipient's graph.

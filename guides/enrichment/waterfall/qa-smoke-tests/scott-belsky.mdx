Scott's payload holds `accomplishment_publications: 0` and `articles: 43`, so we wrote exactly 0 — nothing was rejected, the data never reached the writer. - **Country / Region / State 0, IN_COUNTRY 0, IN_REGION 0 — an environment gap, not the pipeline.** The local reference tables are only partly seeded: 246 countries but **12 regions and 16 cities**. Without the parent nodes the backbone edges cannot be written, and a child with a missing parent is excluded from the seed queue as `awaiting_parent` by design. Fixed by re-seeding `xano-regions` / `xano-cities` and running the locations reconcile — scheduled as one pass once the suite completes, so every fixture is re-dumped against the same corrected environment.
- **Signal NFX matched the wrong person — FIXED 2026-08-13.** This run wrote **Philip Kaplan's** investor profile onto Scott: `"Founder and CEO at DistroKid."`, investments `"Upbeat, fitmob, Reddit, Nuzzel, Medium, Mouth Foods, August Home, FOBO"`, scraped from `signal.nfx.com/investors/philip-kaplan`.

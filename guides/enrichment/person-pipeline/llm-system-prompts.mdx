### Curl Example

```bash
curl -X POST https://openrouter.ai/api/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $OPENROUTER_API_KEY" \
  -d '{
    "model": "moonshotai/kimi-k2.5",
    "temperature": 0.2,
    "max_tokens": 2000,
    "reasoning": {"enabled": false},
    "messages": [
      {
        "role": "system",
        "content": "# Biography Writing System Prompt\n\n## Role\nYou are an AI-powered assistant specializing in copywriting and editing...\n\nABSOLUTE MAXIMUM: 500 characters. NO EXCEPTIONS.\nThe biography MUST contain exactly 1 or 2 line breaks.\n\n**Process this person information:** <person context>"
      }
    ]
  }'
```

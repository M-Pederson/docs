## 1. Executive Summary

The Music Industry waterfall enriches artists, groups, labels, recordings, release-groups, works, events, and places from the **MusicBrainz JSON API** — no scraping, no LLM in the structural path — under a **global 1 request/second ceiling** that shapes the whole architecture: one token bucket (`mb/rate-limit/acquire` #13079), one API choke point (`mb/api/request` #13080), and **one unified drain** (`mb/queue/process-next` #13102) across all six entity queues.

The rebuild target is a Go service on Cloud Run writing AlloyDB (`universe.*`) and the greenfield Universe FalkorDB graph, per the [GCP migration plan](/guides/open-work/orbiter-univers-standalone/enrichment-gcp-migration). Parity-first (decision #3).

Shape of the pipeline:

- **Six get-add gates** (#13087–#13106 family) keyed on **`mbid`** (no URL normalization): 30-day freshness dedup, `gone` tombstones for 404s, sync-enrich at `depth 0 && queue == false`, else queue upsert. The artist gate #13088 is deliberately hardened beyond its five siblings (lifecycle-epoch fence, scope-aware dedup, queue-write readback preconditions).
- **Seven queue writers** (#13081–#13086, #13122) — sole writers of their queues, with **per-entity tier philosophies**: artist = fail-closed tier-1 floor + sanctioned catalog-promoter escape; recording = per-seed budget choke (default 20, rollback on race); label/work = 30-min debounced one-step promotion; event = repair-only floor, no promotion; release-group = preview-gated min; person-resolution = plain min.
- **One drain** #13102 + Task 180 (INACTIVE, 60 s × ≤10 calls): picks the single best **tier-0** row across six queues (`cascade_depth ASC, entity_rank ASC, id ASC`, `next_attempt_at` gated), **lease-locks with a token** (600 s lease / 300 s retry backoff; events 180 s / 60 s), dispatches by entity and `execution_scope`, deletes only on **lease-verified terminal proof**, parks at 24 h after 5 retries (artist rows preserved, others dropped).
- **Artist execution modes** (#13094, 16 phases, 14 fail-closed gates): `core` (verified identity: node, SAME_AS, aliases/dates) → `catalog_preview` (immutable sha256-verified plan: top **3 release-groups + 5 recordings inline, 17 + 15 queued**) → cascade. Root person artists enqueue **person-resolution** (#13121–#13123) and fetch a Serper avatar inline.
- **Identity bridges** — label→Company `SAME_AS` weight 1 + `OWNED_BY`/`ACQUIRED_BY` owner resolution (#13133 family); Music_Artist→master_person `SAME_AS` weight 1 via person-resolution; reverse bridges enter from person/company/IMDB expertise flags (#13171/#13175 via #13185) with a `music_reverse_probe` cache.
- **Graph writes** — `Music_Artist`/`Music_Group` (#13092), `Company:Music_Label` (#13090), per-orchestrator edge sets (MEMBER_OF, PLAYED_ON/PRODUCED/ENGINEERED type-aware, RELEASE_OF/RELEASED_ON/APPEARS_ON, HEADLINED w35/PERFORMED_AT w45/HELD_AT w30, SUBSIDIARY_OF w15, COMPOSED/WROTE/WROTE_LYRICS), all through `send-cypher` #2815 (string-error transport). Edge descriptions are written in-band per-mbid (#13158) with an ACTIVE safety-net cron (Task 181 → #13097).
- **Lifecycle-epoch fencing** — `pipeline_lifecycle_epoch` #767: queue writers and the artist path fail closed while the lifecycle rotates, so wipes/resets cannot interleave with in-flight work.

This spec freezes a **2026-07-31 live snapshot of 86 functions** (Section 4). **No hard freeze is signed off**; the pipeline hardened heavily 2026-07-19 → 07-28 (leases, scopes, epoch fencing, catalog plans) and the narrative docs trail it — Section 21 lists the drift.

Pipeline-specific notes:

- **The 1 req/s limiter is global and fail-open** (`Preserve for parity`): on limiter error, proceed. Pacing lives at ONE choke point; workers must not add second limiters.
- **Retry backoff is linear, not exponential:** #13080 v1.4 sleeps `attempts × 2` seconds (2/4/6/8 s, none after attempt 5); terminal on 200/400/404; network errors collapse to status 0 and retry. Return envelope `{ok, terminal, status, attempts, json}`.
- **Embeddings parity break** (sanctioned, decision #1): Xano writes dual OpenAI-1536 + Gemini-3072 vectors; Universe writes Gemini-1536 only. Reproduce which fields are embedded (`name + disambiguation`, description where generated), not the dual-write.
- **Lease + epoch primitives** belong in `internal/queues`, not per-pipeline code: lease token verify-before-delete, `next_attempt_at` scheduling, and epoch fencing are exactly the shapes AlloyDB implements with `FOR UPDATE SKIP LOCKED` + a fencing table.

## 7. End-to-End Worked Example

### Example A — seed artist, happy path (Nirvana, `mbid 5b11f4ce-a62d-471e-81fc-a69a8278c7da`)

Input (operator seed or bridge entry via #13088):

```json
{ "mbid": "5b11f4ce-a62d-471e-81fc-a69a8278c7da", "name": "Nirvana", "cascade_depth": 0, "queue": false }
```

Expected control flow:

1. Gate #13088: epoch fence passes, no fresh `mb_artist` row → stub ensured → sync-enrich dispatches #13094 (`execution_scope: full`).
2. #13094 P1–P4: lifecycle/identity fences → throttled lookup `GET artist/{mbid}?inc=aliases+tags+genres+ratings+url-rels+artist-rels+event-rels` (through #13079 token + #13080 envelope) → raw JSON saved on `mb_artist`.
3. Node: #13092 MERGEs `Entity:Music_Group {mbid}` (Group type) with dual vectors; registry #13184 records the uuid; finalize #13117 adds group image + LLM description (#13112, reasoning disabled).
4. MEMBER_OF edges for each `member of band` rel (Cobain, Grohl, Novoselic …) with instruments/dates; each member queued at T1 (tier floor: artists enter ≥1; only the catalog promoter writes 0).
5. Catalog: top 3 release-groups + top 5 recordings enriched inline (signal-scored); 17 + 15 queued into the tier-0 lane under the committed, sha256-verified plan; depth-0 events: top 2 inline, next 3 T2, rest T3.
6. Terminal stamp only after committed plan readback: `enriched_at`, `enrich_success: true`.

(Person-artist variant: a depth-0 `Person` artist additionally enqueues person-resolution — #13121 cross-checks MB url-rels against Exa-discovered socials, mints/links `master_person` via the person-gate handoff, writes `SAME_AS` weight 1, then #13242 materializes dates/aliases/IMDb handoff/expertise.)

Expected key AlloyDB writes:

| Table | Key | Important fields |
| --- | --- | --- |
| `universe.entity` + `entity_identifier(kind='mbid', strong)` | mbid per entity | entity_type music_group/…, graph_node_uuid |
| `universe.mb_artist` (source facet) | `mbid` UNIQUE | raw lookup JSON in `enrichment_payload`, enrich stamps |
| queue rows ×(17 RG + 15 rec + members + events) | one per mbid (UNIQUE) | tier, depth 1, `entity_rank`, plan linkage |
| `universe.mb_release_group` / `mb_recording` ×8 inline | mbid | canonical-release selection recorded |

Expected graph writes:

| Node/Edge | Key | Required properties |
| --- | --- | --- |
| `Entity:Music_Group` | `mbid` MERGE | display_label, dual vectors→(Go: Gemini-1536), description via finalize |
| `Entity:Person:Music_Artist` ×members | `mbid` MERGE | type split by MB `artist.type` |
| `MEMBER_OF` ×members | endpoints | instruments, dates, original flag, description in-band (#13158) |
| `Release_Group`/`Recording` nodes ×inline | `mbid` | sub-labels (Album/Single/EP) |

Acceptance checks:

- Re-run inside 30 days → `existing`, zero MB calls.
- Total MB calls for the seed ≈ lookup + 2 browse pages + inline children; **never exceeds 1 req/s globally**.
- Re-run after expiry: MERGE stability — node/edge counts flat, `created_at` unchanged.

### Example B — queue drain, dedup, explicit zero

1. **Tier-0-only drain:** with Task 180 on, only `priority_tier = 0` rows drain. A T2 recording re-discovered twice is promoted stepwise (`max(0, min(existing, incoming) − 1)` per genuine re-discovery, 30-min debounce where the entity has one) and earns its slot; an artist row NEVER self-promotes to 0 (floor 1; only the catalog promoter writes 0).
2. **Explicit zero:** bootstrap rows queued with `priority_tier: 0, cascade_depth: 0` keep both zeros end-to-end (`first_notnull` semantics — the load-bearing Xano trap).
3. **Recording budget race:** two concurrent upserts for a seed at the 20-recording cap — the overshooting insert rolls itself back (`skipped_budget_race`), the seed's queue set stays ≤ 20.
4. **Lease recovery:** kill the worker mid-artist-enrich; after the 600 s lease expires the reclaim pass re-dispatches; the interrupted row closes from durable current-epoch terminal proof without repeating provider calls.

### Foundation

#### `mb/rate-limit/acquire` #13079

Role: In-process token gate pacing MusicBrainz calls to ~1 req/s off singleton `mb_rate_limit#1`. Always grants — fail-open on any error.

Inputs: none.

Output shape: bare boolean `true` — no ungranted path exists in the current code.

Reads/writes: `db.get mb_rate_limit#1` (`last_call_at`) → `db.edit` stamps `last_call_at:now` on grant.
Calls: none. Providers/LLM/Graph/Queue: none.
Idempotency key: n/a (singleton row, no lease/CAS — see flag).
Retry/timeout/failure: single `try_catch`; catch still grants (`$granted=true`) after logging `log_crash` (`note:"rate-limit acquire failed - granting fail-open"`).

Artifact decisions:
- Threshold check is `elapsed<1100ms` but remedy is a flat `sleep(1)` (1s) — spacing can run 1100–2099ms, never <1100ms. `Preserve for parity`.
- No lease/CAS on the row — two concurrent callers can both pass without sleeping. `Open question for Mark` (does a Go rebuild with real goroutine concurrency need an explicit mutex/semaphore, or keep this best-effort?).
- Fail-open on any exception. `Preserve for parity`.

Acceptance checks:
- Two sequential calls ≥1100ms apart never sleep.
- A forced DB error on the singleton read still returns `true` (never blocks a caller).

Open questions: concurrency safety under real parallelism (see above).

func GetAddArtist(ctx context.Context, in Input) (Output, error) {
    epoch := readLifecycleEpoch(ctx, "musicbrainz")
    if epoch == nil || epoch.Status != "ready" {
        return Output{Action: "skipped_wipe_in_progress", Reason: "lifecycle_rotating"}, nil
    }
    if strings.TrimSpace(in.MBID) == "" {
        return Output{Action: "skipped_no_mbid"}, nil
    }
    existing := db.Get(mbArtist, WhereMBID(in.MBID)) // wide row
    if existing != nil && existing.Description == "" {
        stub := buildStubDescription(in.Name) // deterministic JS-equivalent template
        db.Edit(mbArtist, existing.ID, Fields{"description": stub})
    }
    if existing != nil && existing.Gone {
        return Output{Action: "skipped_gone"}, nil
    }
    mode := firstNonEmpty(in.ExecutionMode, "full")
    if existing != nil && isFresh(existing, mode) { // scope-aware, success-flag-gated
        return fromExisting(existing, "dedup_"+mode+"_fresh"), nil
    }
    seedMbid := firstNonEmpty(in.SeedMbid, in.MBID)
    depth := valOrZero(in.CascadeDepth)
    if existing == nil {
        existing = db.Insert(mbArtist, StubRow{MBID: in.MBID, Name: in.Name, Description: buildStubDescription(in.Name), Gone: false, EnrichSuccess: false, CascadeStatus: "pending"})
    }
    if depth == 0 && !valOrFalse(in.Queue) && mode == "core" && valOrZero(in.MasterPersonID) > 0 {
        db.Edit(mbArtist, existing.ID, Fields{"master_person_id": in.MasterPersonID, "master_person_node_uuid": in.MasterPersonNodeUUID, "lifecycle_epoch_uuid": in.LifecycleEpochUUID})
        LinkArtistToPerson(ctx, LinkInput{MBArtistID: existing.ID, MasterPersonID: in.MasterPersonID, MatchMethod: "reverse_seed"}) // #13170, unwrapped
    }
    if depth == 0 && !valOrFalse(in.Queue) {
        enrichResult := RunBaseArtistEnrich(ctx, EnrichInput{ // #13094, unwrapped, cascade_depth:0 literal
            MBArtistID: existing.ID, SeedMbid: seedMbid, LifecycleEpochUUID: in.LifecycleEpochUUID,
            ExpectedMbid: in.MBID, ExpectedMasterPersonNodeUUID: in.MasterPersonNodeUUID, ExecutionMode: mode,
        })
        return Output{Action: "enriched_direct", ExecutionMode: mode, NodeUUID: enrichResult.NodeUUID, EnrichResult: enrichResult}, nil
    }
    if seedMbid == in.MBID && depth > 0 {
        return Output{Action: "skipped_seed", SeedMbid: seedMbid}, nil
    }
    requestedPriority := valOrZero(in.PriorityTier) // "first_notnull:4" is dead — input never null
    queueResult := UpsertArtistQueue(ctx, existing, in, mode) // #13081, unwrapped
    if queueResult.Action == "skipped_stale_lifecycle" {
        return Output{Action: "skipped_stale_lifecycle", QaPassed: true, Warning: false, QueueID: nil}, nil
    }
    if queueResult.QueueID == 0 {
        return Output{}, fmt.Errorf("MusicBrainz queue upsert returned no durable queue id")
    }
    readback := db.Get(queueMBArtist, queueResult.QueueID)
    if readback.MBID != in.MBID || readback.MBArtistID != existing.ID ||
        readback.CascadeDepth > depth || readback.PriorityTier > requestedPriority {
        return Output{}, fmt.Errorf("MusicBrainz queue readback failed ownership parity")
    }
    return Output{Action: "queued", QueueVerified: true, QueueReadback: readback}, nil
}
```

func UpsertArtistQueue(ctx context.Context, in Input) (Output, error) {
    epoch := readLifecycleEpoch(ctx, "musicbrainz")
    if epoch == nil || epoch.Status != "ready" {
        return Output{Action: "skipped_wipe_in_progress", Reason: "lifecycle_rotating", QaPassed: true}, nil
    }
    callerEpoch := valOrEmpty(in.LifecycleEpochUUID)
    if callerEpoch != "" && epoch.EpochUUID != "" && callerEpoch != epoch.EpochUUID {
        return Output{Action: "skipped_stale_lifecycle", QueueID: nil, QaPassed: true, MBID: in.MBID}, nil
    }
    depth := firstNonNull(in.CascadeDepth, 1)
    if in.SeedMbid != "" && in.MBID == in.SeedMbid && depth > 0 {
        return Output{Action: "skipped_seed", QueueID: nil, SourceFunction: in.SourceFunction}, nil
    }
    sanctioned := strings.TrimSpace(in.PromotionSource) == "mb/catalog/promoter"
    restricted := depth > 0
    tier := firstNonNull(in.PriorityTier, 4)
    effectiveTier := tier
    if sanctioned {
        effectiveTier = max(0, tier)
    } else if restricted {
        effectiveTier = max(1, tier)
    } else {
        effectiveTier = max(0, tier)
    }
    existing := db.Get(queueMBArtist, WhereMBID(in.MBID))
    if existing == nil {
        row := buildInsertRow(in, effectiveTier, depth) // promoted_at:null
        newRow := db.Insert(queueMBArtist, row)
        return Output{Action: "inserted", QueueID: newRow.ID, Count: 1, ExecutionScope: newRow.ExecutionScope}, nil
    }
    current := firstNonNullOrUndef(existing.PriorityTier, 4)
    existingRestricted := existing.CascadeDepth > 0 || existing.ExecutionScope == "cascade_only"
    repairedCurrent := current
    if existingRestricted {
        repairedCurrent = max(1, current)
    }
    bestTier := repairedCurrent
    if sanctioned {
        bestTier = min(repairedCurrent, effectiveTier)
    }
    promotionSource, promotedAt := existing.PromotionSource, existing.PromotedAt
    if sanctioned && bestTier < existing.PriorityTier {
        promotionSource, promotedAt = "mb/catalog/promoter", nowMs()
    }
    newDepth := min(existing.CascadeDepth, depth)
    name, sourceFunc, sourceEntity, seedMbid := existing.Name, existing.SourceFunction, existing.SourceEntityMbid, existing.SeedMbid
    if depth < existing.CascadeDepth { // shallower discovery wins provenance
        name = firstNonEmpty(in.Name, name)
        sourceFunc = firstNonEmpty(in.SourceFunction, sourceFunc)
        sourceEntity = firstNonEmpty(in.SourceEntityMbid, sourceEntity)
        seedMbid = firstNonEmpty(in.SeedMbid, seedMbid)
    }
    scope := escalateScope(existing.ExecutionScope, in.ExecutionScope) // catalog_preview > cascade_only > full
    db.Edit(queueMBArtist, existing.ID, Fields{
        "count": existing.Count + 1, "priority_tier": bestTier, "cascade_depth": newDepth,
        "name": name, "source_function": sourceFunc, "source_entity_mbid": sourceEntity, "seed_mbid": seedMbid,
        "execution_scope": scope, "promotion_source": promotionSource, "promoted_at": promotedAt,
        "mb_artist_id": firstNonEmpty(in.MBArtistID, existing.MBArtistID),
        "master_person_node_uuid": firstNonEmpty(in.MasterPersonNodeUUID, existing.MasterPersonNodeUUID),
    })
    return Output{Action: "updated", QueueID: existing.ID, Count: existing.Count + 1, CascadeDepth: newDepth, SourceFunction: sourceFunc, ExecutionScope: scope}, nil
}
```

Role: Single-queue drain core for `queue_person_resolution`.     if in.SandboxMode {
        ctx = withDatasource(ctx, "sandbox")
    }
    epoch := readLifecycleEpoch(ctx, "musicbrainz")
    if epoch == nil || epoch.Status != "ready" {
        return Output{Action: "skipped_wipe_in_progress"}, nil
    }
    nowMs := time.Now().UnixMilli()
    currentEpoch := readLifecycleEpoch(ctx, "musicbrainz") // Fix in Go: reuse the read above
    leaseToken := uuid.NewString()
    if in.ExpectedLifecycleEpochUUID != "" && currentEpoch.EpochUUID != "" && in.ExpectedLifecycleEpochUUID != currentEpoch.EpochUUID {
        return Output{Action: "skipped_stale_lifecycle"}, nil
    }
    reclaimed := reclaimExpiredLeases(ctx, nowMs) // unconditional, all 6 queues, any tier — see below
    if in.ReclaimOnly {
        return summarizeReclaim(reclaimed), nil
    }
    var entity string
    if valOrZero(in.QueueID) > 0 {
        row := db.Get(queueMBArtist, in.QueueID)
        switch {
        case row == nil:
            return Output{Action: "target_missing"}, nil
        case row.Processing:
            return Output{Action: "claim_conflict"}, nil
        case in.ExpectedMBID != "" && row.MBID != in.ExpectedMBID:
            return Output{Action: "rejected_identity", Reason: "mbid_mismatch"}, nil
        case expectedPersonUUIDMismatch(row, in): // first_notnull semantics here
            return Output{Action: "rejected_identity", Reason: "person_uuid_mismatch"}, nil
        }
        db.Edit(queueMBArtist, row.ID, Fields{"processing": true, "lease_token": leaseToken, "lease_expires_at": nowMs + 600000, "last_attempt_at": nowMs, "lifecycle_epoch_uuid": currentEpoch.EpochUUID})
        if in.ClaimOnly {
            return Output{Action: "claimed", LeaseToken: leaseToken}, nil
        }
        entity = "artist"
    } else {
        entity = pickGlobalBestTier0(ctx) // six single-row queries + comparator
        if entity == "" {
            return Output{Action: "empty"}, nil
        }
    }
    switch entity {
    case "artist":
        return dispatchArtist(ctx, nowMs, leaseToken, currentEpoch, in) // replay-skip, execution_scope rewrite, terminal-proof gate
    case "label":
        return dispatchLeafEntity(ctx, "label", RunBaseLabelEnrich, 600000, nowMs, leaseToken)
    case "event":
        return dispatchLeafEntity(ctx, "event", RunBaseEventEnrich, 180000, nowMs, leaseToken) // 60s backoff step
    case "work":
        return dispatchLeafEntity(ctx, "work", RunBaseWorkEnrich, 600000, nowMs, leaseToken)
    case "release_group":
        return dispatchLeafEntity(ctx, "release_group", RunBaseReleaseGroupEnrich, 600000, nowMs, leaseToken)
    case "recording":
        return dispatchLeafEntity(ctx, "recording", RunBaseRecordingEnrich, 600000, nowMs, leaseToken)
    default:
        return Output{Action: "unknown_entity"}, nil // defensive, unreachable
    }
}

    defer func() {
        if r := recover(); r != nil {
            logCrash(ctx, "mb_node", false, r)
            out, err = Output{Action: "error", Error: fmt.Sprint(r)}, nil
        }
    }()

    if label == nil {
        return Output{Action: "missing_row"}, nil
    }
    if label.NodeUUID == "" {
        return Output{Action: "no_node"}, nil
    }

    ownExists := cypherCountOwnedByEdges(ctx, label.NodeUUID) > 0
    var ownerNodeUUID, ownerMethod string
    var ownerConfidence float64
    if ownExists {
        _ = GetLabelOwnerEdge(ctx, label.NodeUUID) // #13156 readback — populated then DISCARDED below
    }
    // Reset happens unconditionally whenever mbid is non-empty (essentially always)
    ownerNodeUUID, ownerMethod, ownerConfidence = "", "", 0
    if tierOwner, ok := parseNativeOwnerRelation(label.JSON.Relations); ok { // Tier 1
        ownerMethod, ownerConfidence = "mb_subsidiary", 1
        ownerNodeUUID = resolveOrCreateCompany(ctx, tierOwner, label.NodeUUID) // domain via #13116 if missing, upsert via #12558

        resolved := ResolveLabelOwner(ctx, ResolveInput{Name: selfName, LabelType: label.Type, Area: label.Area}) // #13132
        if resolved.Accepted {
            ownerMethod, ownerConfidence = "none", 0 // overwritten below
            ownerNodeUUID = resolveOrCreateCompany(ctx, resolved, label.NodeUUID)
            ownerMethod, ownerConfidence = "acquisition_text_or_exa", resolved.Confidence // simplified; see notes for exact field routing

    }
    acquirer := scanPrimaryWaveFallback(label.JSON.Relations) // narrow, hardcoded case-insensitive "primary wave" match
    // Exa acquisition_date/year forward-merge onto acquirer if still empty
    if acquirer.Name != "" {
        acquirerNodeUUID := resolveOrCreateCompany(ctx, acquirer, label.NodeUUID)
        writeAcquiredByEdge(ctx, label.NodeUUID, acquirerNodeUUID, acquirer) // weight 25, no stale-edge cleanup

            ownerNodeUUID, ownerMethod = acquirerNodeUUID, "acquisition_text"

    return Output{Action: "done", OwnerNodeUUID: ownerNodeUUID, OwnerMethod: ownerMethod /* + 20 more fields */}, nil

### Reverse Bridges (13168–13175, eight functions)

Two mirrored four-function chains (detect → find → enter → link) run *after* the forward person/company enrichment waterfalls, looking for MusicBrainz identity on entities Orbiter already knows about. Person side: 13171→13168→13169→13170. Company side: 13175→13173→13174→13172. **The two sides have diverged sharply in hardening maturity** — the single biggest rebuild-relevant finding in this subsystem.

**Entry semantics (both sides):** `find-*` is a pure resolver (no writes) returning a `decision` object; the orchestrator dispatches to `enter-*` only when `decision.confidence>=0.5 && decision.mbid` non-empty. `enter-*` always bootstraps a tier-0 `queue_mb_*` row via `get-add/*` regardless of confidence — confidence/matched only gate whether the entity gets stamped and SAME_AS-linked **immediately** vs. left for the forward-path drain to confirm later.

**Shared MB search/adjudication contract (13168 & 13173, via #13080):** Lucene query per entity type, `limit:6` search, up to 3 per-candidate detail fetches (`inc:url-rels+aliases+tags`). Deterministic scoring prefers a hard `url_rel` host match (confidence 0.9, `matched:true`); absent that, falls through to LLM adjudication when `skip_llm!=true`.

**Shared LLM adjudication contract (13168 & 13173, identical wiring, full detail in §11):** model `google/gemini-3.1-flash-lite`, `temperature:0`, `reasoning:{enabled:false}`, `max_tokens:500`, single system-role message, `timeout:40`. Merge rule: `matched=(llm.confidence>=0.75) && (corroborating_field not name/fame-ish)`. Entire LLM step is one `try_catch` — on any failure, both functions silently fall back to the deterministic decision. **The LLM CAN set `matched:true`** — not exclusive to the deterministic `url_rel` path, despite both `enter-*` docstrings implying otherwise (load-bearing for 13174's gap, see below).

**Shared SAME_AS edge contract (13170 & 13172, identical Cypher shape):** `MERGE (a)-[e:SAME_AS]->(p) ON CREATE SET ... weight=1, match_method, confidence ON MATCH SET updated_at[, description coalesce]`. Both endpoints matched by generic `Entity{uuid}`. `weight` set only `ON CREATE`, never reset on rerun.

        return Output{Action: "skipped_wipe_in_progress"}, nil

        entered := EnterArtist(ctx, EnterInput{MasterPersonID: in.MasterPersonID, MBID: bridged.MBID, Confidence: 1, Matched: true}) // idempotent re-verify
        return Output{Action: "reentered_materialized", MBArtistID: bridged.ID, ArtistNodeUUID: bridged.NodeUUID, Entered: entered}, nil

    isMusic := detectMusicSignal(ctx, in.MasterPersonID) // llm===true -> music; fk===true -> music EVEN IF llm===false; llm===false -> not music; else name-token fallback
    if !isMusic {
        return Output{Action: "skipped", Reason: "no_music_expertise"}, nil

}

First map row where `edge_type` matches AND (`attr_field=="none"` OR no `attr_contains` OR haystack contains it) wins — haystack is `role` **only if `attr_field==="role"` literally**; every other value (including `"instruments"` or a typo) reads `instruments` instead. `min_credits` gate routes to `proposed[]` vs `below_threshold[]`.

Idempotency key: two independent mechanisms — graph-side CONTAINS-guarded `ON MATCH SET` (min/max-wins, dedup), and Xano-side the 711 evidence-CONTAINS check before #12925 (a full skip, not a merge).

Artifact decisions:
- `attr_field` special-cases only the literal `"role"` string; every other value routes through `instruments` identically to `"none"`. `Preserve for parity`.
- Confidence-multiplier floor (`cs=confidence>0?confidence:1`) prevents a zero/negative-confidence map row from zeroing `expertise_strength` — deliberate floor. `Preserve for parity`.
- 711 dedup check only inspects `row[0]` — if `person_has_expertise` ever legitimately holds >1 row for the same pair, later rows are invisible to dedup. `Preserve for parity` as observed.
- Zero-credit or empty-edge_type tuples are dropped silently before ever reaching `unmatched[]`. `Open question for Mark` — confirm the silent drop (vs. surfacing it) is intended.

Acceptance checks: a credit tuple with `attr_field=="instruments"` (a plausible but non-special-cased value) reads from the `instruments` haystack, not `role`; a re-run of an already-written HAS_EXPERTISE edge with a lower `weight` and higher `expertise_strength` updates both fields independently per the asymmetric merge rule.

Open questions: silent zero-credit/empty-type drop (above).

## 9. Orchestration State Machine

**Queue-row lifecycle (all six MB queues):**

```text
pending ──pick (tier-0, rank order, next_attempt_at ≤ now)──▶ leased(token, 600s / event 180s)
  leased ──terminal proof (lease-verified)──▶ deleted
  leased ──retryable failure──▶ pending (retry_count++, next_attempt_at += 300s·retries / event first 60s)
  leased ──lease expiry──▶ reclaimed by next drain pass
  retry_count ≥ 5 ──▶ artist: preserved + parked(24h) · others: deleted («dropped»)
  epoch mismatch at any fence ──▶ skipped_stale_lifecycle (row untouched)
```

**Artist execution scopes (#13094 / #13102 v2.4–v2.9):**

```text
full (default, sync path) ─────────────▶ all 16 phases
core (drain, root person artists) ─────▶ identity only: node + SAME_AS + aliases/dates + lifecycle probe
catalog_preview (drain continuation) ──▶ verified core precondition → immutable 3+17/5+15 plan
                                          → inline anchors → committed readback → cascade terminal proof
cascade_only (schema value) ──────────▶ NO dedicated branch — currently executes as full
                                          (`Open question for Mark`)
deferred_preview_pending ─────────────▶ clean lease release, retry_count unchanged, 120 s recheck
stall guards: 45-min preview age · no_progress_count ≥ 8 · retry ≥ 5 → red
```

**Per-orchestrator phase shape** (`mb_lookup → mb_node → mb_node_finalize → mb_edges → mb_cascade → stamp`, phases `try_catch` → `log_crash` with the 4-value phase enum): the six orchestrators differ materially in failure posture — #13094 is fail-closed (14 preconditions gate the success stamp), #13100 has a hard 3-way success gate (node/description/edges), #13105 hard-bails early on node failure, while **#13091, #13099, #13101 stamp `enrich_success: true` unconditionally** even when phases failed (`Open question for Mark` — biggest fix-in-Go candidate, Section 22).

**Person-resolution lifecycle:** `queue_person_resolution` rows drain via #13123 (plain `processing` boolean lock — no lease token, no epoch fence; flagged), dispatch #13121, delete on success, linear 5-min-per-retry backoff, drop after 5.

### FalkorDB via `mvp/falkor/send-cypher` #2815 (transport recap)

Every graph write and read across all 59 music-specific functions goes through this one function — it is the single most load-bearing shared dependency in this pipeline. Five-line recap (full contract lives with the shared substrate, per the task's exception):
- **Returns Cypher errors as strings in the response body, never throws** — a malformed or logically-failing Cypher statement returns normally with an error payload embedded, not an exception. Every `try_catch` wrapped around a `send-cypher` call in this pipeline can therefore only catch true transport/network failures, never a Cypher-level error.
- Only a minority of call sites in this pipeline defensively check `typeof response === 'string'`/`!response` before treating a write as successful (`mb/qa/get-label-owner-edge` #13156 and `mvp/music/backfill-on-record-label-edges` #13131 are the two functions that do this consistently across every call site; most others, including several `OWNED_BY`/`ACQUIRED_BY` write sites in #13133/#13134, do not).
- Cypher strings across this pipeline are hand-built via `.push()`/`.join(' ')` string concatenation (a documented FalkorDB single-line parser workaround) rather than template literals — preserve the resulting single-line query shape in Go, not the JS concatenation mechanism.
- No retry/backoff shape is visible from any of the 59 functions' own code — retry, if any, is internal to #2815 itself (out of scope here).
- Go client notes: the shared FalkorDB helper should centralize response-shape parsing (`r.data\|\|r.result\|\|[]`, array-of-array vs. array-of-object row unwrapping — duplicated locally in at least 6 of the functions documented in §8) and should surface a typed error for a string-shaped Cypher-error response, closing the gap most of this pipeline's write sites currently have.

```sql

- Lease: claim sets `lease_token`, `leased_until = now + 600s` (event 180 s). Edge-level flags:
- **COMPOSED/WROTE_LYRICS/WROTE have no Person/Group type split** — all three MERGE the artist as `Music_Artist{+Person}` unconditionally, unlike every other credit-edge family in this waterfall (PERFORMED/PLAYED_ON/PRODUCED/ENGINEERED on the recording side, HEADLINED/PERFORMED_AT on the event side all split by `r.artist.type`). A band credited as `arranger`/`composer` on a work hits the same node-duplication collision that recording's split was specifically built to avoid (the "Nirvana collision," per recording's own v1.2 changelog). `Open question for Mark` — confirm intentional (works rarely have group composers) or backport the split.
- **OWNED_BY / ACQUIRED_BY divergent envelopes** (see table) — flagged twice above because it affects both the write shape and the idempotency/cleanup behavior; treat as one decision for Mark, not two.
- **SAME_AS weight is set only `ON CREATE`, identically on both bridge directions** — a re-run never resets weight even if the match_method/confidence inputs would imply a different value on replay.
- This waterfall also writes `HAS_EXPERTISE` edges from `mvp/music/mb-credits-to-expertise` #13160 (see §8, Person Resolution group) — omitted from the table above since it is co-owned with the person/expertise substrate and its full envelope (asymmetric min/max-wins merge, `expertise_strength` formula) is already specified in that function's §8 sheet.

### Description lifecycle (all music edges)

Every edge above that doesn't get a deterministic description at write time (i.e. everything except MEMBER_OF's explicit `NULL`, and Event's HEADLINED/PERFORMED_AT/HELD_AT which are deterministic-and-always-overwritten) follows the same three-stage lifecycle, fully specified in §8's Edge Descriptions group:

1. **Null-on-create** — the edge is written with `description`/`description_generated_at` absent/`NULL` by its owning orchestrator.
2. **In-band completion** — `mb/edge/write-missing-music-edge-descriptions-for-mbid` #13158 is called inline, right after the owning orchestrator finishes touching that entity's edges, scoped to ONE mbid (25-type allowlist, **includes `ACQUIRED_BY`**, no label gate — trusts `mbid` to be exclusively music-scoped).
3. **Cron safety net** — `mb/tool/backfill-music-edge-descriptions` #13097 (Task 181, **ACTIVE**) sweeps ALL pending music edges by type+label allowlist (24 types, **omits `ACQUIRED_BY`** — the cron path never backfills acquisition-edge descriptions on its own; only step 2's in-band path covers them).

Both step 2 and step 3 funnel through the same writer, `mb/edge/write-music-edge-description` #13096, which applies the deterministic HEADLINED/PERFORMED_AT/HELD_AT templates directly and falls back to the LLM generator `mb/edge/create-music-edge-description` #13095 for everything else. `description_generated_at IS NULL` is a **permanent** one-time flag (not a time window) — once set, an edge falls out of both selection Cyphers forever unless #13097's `mode="reset"` explicitly nulls it back out. No lease/lock exists on graph edges, so overlapping cron+in-band invocations can select and describe the same edge concurrently (last-write-wins, a wasted but harmless duplicate LLM call) — an accepted "safety net" gap, not a hard bug.

## 17. Error Handling and Observability

- **Phase envelope:** `log_crash` with the strict 4-value music phase enum (`mb_lookup`/`mb_node`/`mb_edges`/`mb_cascade` — finalize/terminal events borrow the nearest phase; in Go use precise phase names and keep the green/red rule: empty `error_message` = telemetry).
- **Failure posture varies by orchestrator** — this is currently the pipeline's biggest inconsistency (fail-closed #13094/#13100 vs unconditional-success #13091/#13099/#13101, early-bail #13105). Parity default: reproduce; Section 22 #1 proposes the fix.
- **No kill switch by design** — pausing Task 180 is the manual kill (decided 2026-06-11); layers: dedup gate, upsert dedup, depth cap, tier caps, 1 req/s.
- **API health:** #13080's envelope records `attempts` + `attempt_history`; a retried-then-succeeded call currently emits no telemetry (`Fix in Go`: counter).
- **Graph writes** ride `send-cypher` #2815's string-error contract; #13117 marks description/vector success without checking the Cypher matched a node (`Fix in Go` — honest status, unchanged control flow).
- Go: structured logs per run_id/mbid/phase; metrics for lease reclaims, epoch-fence skips, budget rollbacks, preview stalls, tier-0 lane depth.
